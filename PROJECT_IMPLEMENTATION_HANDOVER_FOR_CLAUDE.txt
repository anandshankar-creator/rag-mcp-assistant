1. EXECUTIVE SUMMARY & ARCHITECTURAL IDENTITY
================================================================================
This repository contains a general-purpose, evidence-grounded Personal AI Assistant
architecture built to provide capabilities comparable to ChatGPT and Claude, but
uniquely differentiated by:
1. Local-First Knowledge Grounding: Private documents, syllabi, and schedules are
   indexed locally into dense vector storage (ChromaDB + sentence-transformers)
   with strict refusal when confidence falls below the similarity threshold (0.30).
2. Intelligent Web Research Fallback: When local knowledge is absent, the system
   transparently falls back to free web research (via `ddgs`), filtering results
   through a curated Domain Trust Authority engine (Tier 1 Academic/Gov/Docs,
   Tier 2 Reputable Tech/Journalism) with verified URL citations.
3. Model Context Protocol (MCP) Integration: Connects modular, decoupled FastMCP
   servers for Google Workspace (Calendar v3, Gmail v1, Tasks v1, Drive v3) and
   local utilities (APScheduler alarms, PDF generation, RFC 5545 .ics generation).
4. Dynamic Multi-Agent Planning & Execution: Deconstructs composite user requests
   into ordered JSON DAGs (Planner Agent) and executes them sequentially in LangGraph
   (Executor Node) with dynamic state passing and Human-in-the-Loop action safety.
5. High-Availability LLM Rotation: Implements thread-safe, round-robin Gemini API
   key rotation with automatic 429/ResourceExhausted recovery and cooldown timers.

[GOAL G3] Web answers use only TRUSTED sources chosen by trust ranking.
STATUS: IMPLEMENTED & VERIFIED
FILES & FUNCTIONS:
- `rag/trust_ranker.py` (`DomainTrustRanker.calculate_trust_score`, `rank_and_filter_results`)
DESCRIPTION:
Does not rely on raw search engine rank. Uses a tiered domain authority model:
- Tier 1 (Score 0.90-1.0): Academic (`.edu`, `.ac.uk`), Government (`.gov`, `.gov.in`),

- Tier 2 (Score 0.70-0.85): Peer-reviewed and technical outlets (`realpython.com`, `geeksforgeeks.org`).
- Untrusted (Score < 0.40): Content farms, spam boards (`quora.com`, `pinterest.com`).
Results are ranked using a composite score: `0.65 * trust_score + 0.35 * search_rank`.

supplies page excerpts into a strict grounding prompt. The LLM is commanded to answer
ONLY from provided text and cite each claim with exact URLs `[URL]`. Extracted citations

6. VIVA DEFENSE & ACADEMIC REVIEW GUIDE (KTU B.TECH FINAL YEAR)
================================================================================

Q1: Why did you choose Model Context Protocol (MCP) instead of standard Python function calling?
A1: Traditional function calling tightly couples tool declarations to a single LLM
provider's API format (e.g. OpenAI function schemas or Gemini functionDeclarations).
Model Context Protocol (FastMCP) decouples tool servers into independent, modular
processes. Tools are discovered dynamically via `list_tools()` at runtime, normalized
into standard JSON Schema, and executed over standardized protocols. If a new server
(e.g. Google Services or Home Automation) is added, zero lines of core orchestrator
code need modification.

Q2: How does your architecture measurably reduce hallucinations?
A2: Hallucination reduction is enforced at two distinct layers:
1. Cosine Distance Refusal Gate: Candidate vector chunks are retrieved from ChromaDB.
   If max similarity < 0.30, the generator refuses to answer rather than hallucinating
   an answer from parametric memory.
2. Evidence Grounding & Verification: In both local RAG and web fallback, prompts are
   strictly bounded to provided context chunks/pages. Answers are parsed to verify
   that in-text citations (`[file, page]` or `[URL]`) genuinely match the retrieved evidence.

Q3: How does domain trust ranking differ from standard search engine rank?
A3: Commercial search engines rank pages using SEO optimization, user click signals,
and ad bidding, which frequently surfaces user forums, content mills, and clickbait.
Our `DomainTrustRanker` evaluates source authority independently: Tier 1 (.edu, .gov,
official docs, Wikipedia) receives a 0.9-1.0 credibility score, while content farms
(Quora, Pinterest, BuzzFeed) are penalized or filtered out. The composite score weights
domain credibility at 65% and search rank at 35%.

Q4: What happens if Gemini API rate limits (HTTP 429) are encountered?
A4: `GeminiKeyManager` maintains a thread-safe pool of configured API keys. Upon receiving
a 429 / RESOURCE_EXHAUSTED error, it temporarily puts the exhausted key on a 60-second
cooldown, rotates to the next available key in round-robin fashion, and transparently
retries the request without crashing user sessions.

Q5: Why is Human-in-the-Loop (HITL) confirmation necessary in autonomous agents?
A5: Read-only actions (retrieval, search, summarization) are idempotent and risk-free.
Consequential actions (sending emails, modifying external calendars, deleting tasks)
have real-world, irreversible side effects. The architecture enforces an explicit
confirmation gate: unless explicit confirmation is verified, the agent halts dispatch
and generates a structured draft preview (`preview_email`) awaiting user consent.
