# Academic Report Formatting Guide (KTU / LMCST Standard)

This guide documents the exact formatting, layout, typography, and citation conventions extracted from the approved sample report (*Guardian AI Phase 1 Report*). All subsequent project documentation and the final B.Tech project report must adhere strictly to these parameters.

---

## 1. Page Layout & Margins

| Dimension | Specification | Notes |
|---|---|---|
| **Paper Size** | Standard A4 ($210 \times 297\text{ mm}$) | Portrait orientation throughout main body |
| **Left Margin** | $1.25\text{ inches}$ ($31.75\text{ mm}$) | Required gutter allowance for hard binding |
| **Right Margin** | $1.0\text{ inch}$ ($25.4\text{ mm}$) | Standard outer boundary |
| **Top Margin** | $1.0\text{ inch}$ ($25.4\text{ mm}$) | Standard top boundary |
| **Bottom Margin** | $1.0\text{ inch}$ ($25.4\text{ mm}$) | Standard bottom boundary |

## 2. Typography & Hierarchy

| Element | Typeface | Size | Weight | Spacing / Case |
|---|---|---|---|---|
| **Document Title** | Times New Roman | 16–18 pt | Bold | UPPERCASE, Centered |
| **Chapter Numbers** | Times New Roman | 14 pt | Bold | "CHAPTER 01", UPPERCASE, Centered |
| **Chapter Titles** | Times New Roman | 14 pt | Bold | UPPERCASE, Centered |
| **First-Level Headings** (e.g. 1.1) | Times New Roman | 12 pt | Bold | Capitalize Each Word, Left-Aligned |
| **Second-Level Headings** (e.g. 1.1.1) | Times New Roman | 12 pt | Bold / Italic | Sentence case, Left-Aligned |
| **Body Text** | Times New Roman | 12 pt | Regular | 1.5 Line Spacing, Fully Justified |
| **Table Text** | Times New Roman | 10–11 pt | Regular | Single Spacing, Clean Grid |
| **Table Headings** | Times New Roman | 10–11 pt | Bold | Centered / Left-Aligned |
| **Figure / Table Captions** | Times New Roman | 11 pt | Regular / Bold | "Fig X.Y : Title", Centered Below Figure |
| **Code & Schemas** | Courier New / Consolas | 10 pt | Regular | Single Spacing, Light Background Shading |

## 3. Pagination & Numbering Scheme

1. **Preliminary Pages:**
   - Unnumbered: Title Page, Declaration Page, Certificate Page.
   - Lower-case Roman numerals:
     - Acknowledgement: Page `i`
     - Abstract: Page `ii`
     - List of Tables: Page `iii`
     - List of Figures: Page `iv`
     - Table of Contents: Roman numerals continued or unnumbered if single page.
2. **Main Body Chapters:**
   - Arabic numerals starting at `1` on the first page of **CHAPTER 01 INTRODUCTION**.
   - Numbers placed in the footer, centered or bottom-right.
   - Numbering runs continuously through Chapters 1 to 7.
3. **Appendix & Post-Text:**
   - Continues Arabic numbering from the last chapter through Appendix slides and References.

---

## 4. Tables and Figures Guidelines

- **Table Placement & Captioning:**
  - Table captions appear **ABOVE** or **BELOW** the table following KTU guidelines: `Table X.Y : Table Title` (e.g., `Table 3.1 : Hardware Requirements`).
  - Tables must have clean horizontal and vertical gridlines with distinct bold header rows.
  - Every table must be referenced explicitly in preceding body text (e.g., *"As summarized in Table 3.1..."*).
- **Figure Placement & Captioning:**
  - Figures must be centered horizontally on the page.
  - Figure captions appear **BELOW** the illustration: `Fig X.Y : Figure Title` (e.g., `Fig 5.1 : System Architecture Diagram`).
  - Followed by a concise 1–2 sentence explanatory note in the text describing what the diagram illustrates.

---

## 5. Appendix (Presentation Slides) Format

- The approved sample includes an **APPENDIX** section containing the complete oral presentation slide deck.
- Slides are rendered cleanly in 16:9 widescreen format, displayed 2 per page with subtle borders.
- Slide contents cover:
  - Slide 1: Title and Project Name
  - Slide 2: Team Members and Guide
  - Slide 3: Contents Overview
  - Slide 4–5: Introduction & Societal Context
  - Slide 6–7: Objectives
  - Slide 8: Literature Review Comparative Matrix
  - Slide 9: Existing Systems
  - Slide 10: Gap Analysis
  - Slide 11: Proposed Architecture Overview
  - Slide 12: High-Level System Flowchart
  - Slide 13–15: Key Features & Modules
  - Slide 16–17: Hardware & Software Requirements
  - Slide 18: Future Enhancements
  - Slide 19–20: Conclusion
  - Slide 21–24: Implementation UI Screenshots
  - Slide 25: Slide References
